# QA Checklist

## 页面规格

- [ ] 每页 16:9
- [ ] 页面尺寸 1280×720
- [ ] 打印 PDF 正常分页
- [ ] PDF 中没有编辑工具、手柄、辅助线

## 编辑能力

- [ ] 所有文字可编辑
- [ ] 固定文字可编辑
- [ ] 组件可拖动
- [ ] 组件可缩放
- [ ] 组件可删除
- [ ] 可删除整页
- [ ] 可插入自由文字
- [ ] 可在当前页插入自由图片，不能默认插入到封面页
- [ ] 选中图片后可替换本地图片
- [ ] 选中图片后可调整宽高、层级和透明度
- [ ] 表格单元格支持左对齐 / 居中

## 图片能力

- [ ] 页面规划阶段预留图片区域
- [ ] 图片区域可双击插入图片
- [ ] 图片能自动适配区域
- [ ] 图片支持 cover / contain / fill
- [ ] 自由图片默认无边框、无虚线、无占位背景
- [ ] 每页可设置背景图
- [ ] 背景图可调整透明度

## 视觉与内容

- [ ] 页面不是全是文本块
- [ ] 页面布局服务内容
- [ ] 内容密度足够
- [ ] 视觉风格符合用户要求
- [ ] 没有照搬模板导致表达僵硬
- [ ] 默认风格已采用“平安汇报模版”，除非用户明确要求其他风格
- [ ] 使用平安橙标题、深绿成果强调、浅绿蓝背景
- [ ] 内容页有右侧橙色竖条/点阵或等效品牌页边装饰
- [ ] 页脚包含注释区和右下页码
- [ ] 卡片为白底薄线框，避免大圆角、深色大屏、漂浮装饰球
- [ ] 图表或指标页使用灰/橙/绿的克制配色

## 售前方案专项检查

- [ ] 售前/产品/客户方案已读取 `references/pingan-presale-template.md`
- [ ] 已加载 `resources/knowledge/presale`，本机环境可 fallback 到完整售前知识库
- [ ] 已加载 `resources/pingan-materials/99_索引与说明/html_asset_map.json`
- [ ] 页面结构包含客户痛点、能力体系、产品权益、履约流程、案例证明或合作动作
- [ ] 产品权益、价格、次数、等待期、服务范围有本地来源或标注需复核
- [ ] 使用素材时已记录 `PRESALE### p##` 或 `PRESALE###_A####`
- [ ] 默认素材满足 `safe_for_external=true` 且 `pa_style_score>=4`
- [ ] 未默认调用 `needs_review_iconfont` 素材
- [ ] 客户商标、第三方品牌、人物肖像已提示外发授权风险
- [ ] 手机截图使用 contain 或等效方式，未被裁切变形
- [ ] 服务说明、注释、免责声明未被删除

## 知识真相专项检查

- [ ] 若存在完整 `知识库/`，已优先读取 `知识调用架构.md`
- [ ] 已使用 `实体索引.csv` 和 `关系索引.csv` 做主题路由
- [ ] 逐页稿已标注 `knowledge_mode`、`entity_refs`、`relation_refs`、`wiki_sources`、`source_refs`、`truth_status`
- [ ] 业务结论已回到主题 Wiki 和来源追溯层
- [ ] 价格、权益次数、医学口径、等待期、服务范围等易变事实已标 `needs_review` 或给出原始来源
- [ ] 若只使用便携知识，已明确标记 `portable_only`

## 回退规则

- [ ] 任一核心编辑能力失败，阻断交付
- [ ] PDF 输出异常，回退修复
- [ ] 页面内容太空，回退到页面规划
