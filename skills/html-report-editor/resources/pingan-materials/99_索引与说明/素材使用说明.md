# 平安好医生 HTML 素材库使用说明

本素材库用于可编辑 HTML 汇报材料和 PPT 风格页面，不是泛素材仓库。

## 调用原则

- 默认使用 `99_索引与说明/html_asset_map.json` 中的 `defaults`。
- HTML 图片元素建议保留 `data-asset-id` 和 `data-replacement-group`，便于后续替换。
- `safe_for_external=false` 的素材只能作为候选或内部草稿，外发前必须复核授权和品牌露出。
- `06_版式参考_不直接入页` 只用于观察版式，不作为页面视觉元素直接调用。

## HTML 示例

```html
<img class="pa-asset-icon" src="resources/pingan-materials/01_图标_icon/服务能力/pa_icon_shield_cross.svg" data-asset-id="gen.icon_shield_cross" data-replacement-group="service.immunity" alt="免疫防护">
```

## 质量边界

- 主色控制在平安橙、黑灰、白底、少量健康绿。
- 不使用五颜六色、emoji 风、儿童卡通风素材。
- iconfont 素材仅作为单色 SVG 候选，默认不外发。
