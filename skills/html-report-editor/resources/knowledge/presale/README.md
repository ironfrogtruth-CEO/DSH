# 售前材料规范与素材库

## 定位

本目录沉淀 10 份平安好医生售前交付材料的结构、视觉 VI、样式组件和可复用图片素材。

用途：

- 生成客户售前方案、产品介绍、合作交流材料。
- 为 `html编辑器skill` 提供默认售前方案设计语言。
- 为 PPT/HTML 汇报材料提供可追溯的图片、页面参考和组件规范。
- 支撑后续按客户行业、产品类型、合作模式快速复用售前叙事结构。
