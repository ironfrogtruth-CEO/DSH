# 售前材料内容结构

## 1. 通用售前叙事骨架

10 份材料虽然面向不同客户和产品，但底层结构高度一致，可沉淀为“客户问题 - 平安能力 - 产品方案 - 履约路径 - 合作成效”的售前方案骨架。

| 顺序 | 模块 | 作用 | 常见页面表现 |
| --- | --- | --- | --- |
| 1 | 封面 | 明确客户/行业/产品主题，建立正式交付感。 | 大标题、年份、客户名或合作项目名、平安健康 Logo/品牌色。 |
| 2 | 目录 | 给出材料的决策路径。 | `CONTENT/目录`，3-4 段纵向章节。 |
| 3 | 行业背景/客户痛点 | 说明为什么客户需要健康服务、医养服务或增值权益。 | 政策沿革、行业趋势、员工/业主/老人/用户痛点。 |
| 4 | 平安健康定位 | 建立公司可信度。 | 集团生态、上市主体、用户规模、医生资源、服务经验。 |
| 5 | 能力体系 | 展示“线上+线下+医养+支付/保险/健康管理”的综合能力。 | 家医、专医、名医、就医、健康管理、商城、O2O。 |
| 6 | 产品/权益设计 | 将能力打包成客户可采购、可售卖、可赠送的产品。 | 三档会员、月卡/年卡、补充医疗、硬件+服务包。 |
| 7 | 服务流程/履约路径 | 让客户相信方案能落地。 | 用户领取、实名认证、权益选择、服务使用、订单记录。 |
| 8 | 场景化方案 | 按客户行业或目标人群组合产品。 | 运营商、地产、企业员工、老人、硬件用户、银行 App 嵌入。 |
| 9 | 合作案例/数据证明 | 证明方案已经被验证。 | 中国移动、华为手表、招商地产、天保基建、银行 H5 等案例。 |
| 10 | 合作模式/商务建议 | 引导下一步动作。 | 分销、权益赠送、插件化对接、系统输出、营销政策。 |
| 11 | 附录/FAQ/清单 | 降低实施不确定性。 | 产品清单、服务说明、价格表、FAQ、合作资源清单。 |
| 12 | 感谢页 | 形成正式收口。 | `感谢审阅/谢谢/让每一位用户拥有平安健康`。 |

## 2. 逐材料结构

### PRESALE001 居家养老政企合作版

结构主线：养老政策与社会问题 -> 平安居家养老能力 -> 三心价值与十大场景 -> 合作机会与案例 -> 产品服务清单。

关键模块：

- 中国养老现状、银发经济、9073 居家养老格局。
- 平安愿景：综合金融、医疗养老、科技驱动。
- 三位一体养老管家、五管十维监督平台、护住乐医四联体。
- 医养合作机会：完整医养解决方案、会员权益、产品+服务、服务/商品分销。
- 银行 App 无感嵌入、中国移动权益、华为硬件服务闭环等案例。
- 附录列出养老对外合作产品服务清单。

适配输出：养老/医养合作方案、政企合作方案、银行/运营商/硬件客户的医养权益方案。

### PRESALE002 企业补充医疗营销材料

结构主线：企业健康管理重要性 -> 补充医疗政策依据 -> 员工就医痛点 -> 平安企业健康保障计划 -> 产品组合。

关键模块：

- 员工健康管理与企业生产力、满意度、忠诚度关联。
- 补充医疗、委托管理、税前列支等政策依据。
- 寻医难、会诊难、诊前难预约、诊后无追踪、过度诊疗等痛点。
- 服务特色：名医服务、联合会诊、到线、到院、到企、到家、控费降本、合规保障。
- 产品组合：健康委托管理、会员制健康管理服务、保险+。

适配输出：央国企/大型企业员工福利、补充医疗、健康委托管理售前材料。

### PRESALE003 企康会员产品手册

结构主线：会员制产品总览 -> 特色服务权益 -> 服务使用流程 -> FAQ。

关键模块：

- 企业需求从医保、补充医疗扩展到医疗健康服务。
- 员工从入职到退休存在健康管理、日常购药/体检/齿科、名医名院、重疾医疗需求。
- 三档会员：个人会员、家庭会员、尊享会员。
- 平安家医 6 项服务和自选服务组合。
- 特色权益：门诊预约、住院安排、陪诊、名医视频、慢病管理、居家快检、心理、洁牙、体检、康复护理、智能设备等。
- 履约流程覆盖好福利 App、企业宝 App、平安健康 App、开卡礼选择、权益选择、权益使用、重兑、服务记录查询。
- FAQ 处理权益选择窗口期、撤销重选、增减员等问题。

适配输出：产品手册、报价附件、客户 HR/工会/员工福利说明书。

### PRESALE004 健康宝服务营销手册

结构主线：企业健康管理痛点 -> 服务链路 -> 健康宝产品形态 -> 履约路径和页面展示。

关键模块：

- 久坐肥胖、工作压力、饮食不均衡、睡眠和心理问题。
- 四师共管：全科/专科医生、私人教练、营养师、心理咨询师。
- 健康宝基础版、升级版，覆盖测评、记录、课程、计划、AI 工具、真人咨询。
- 服务流程：测评建档、专属方案、咨询跟踪、课程和线下资源。
- 履约路径：首页、计划、咨询、AI 食谱、睡眠工具、运动饮食记录、课程页面。

适配输出：员工健康管理、检后管理、运动营养心理睡眠服务方案。

### PRESALE005 养老音箱材料

结构主线：智能音箱作为适老入口 -> 尊老管家/家庭医生/急救助手 -> 定制案例。

关键模块：

- 智能管家链接平安家医与尊老管家。
- 家庭医生全年无限次服务，覆盖健康档案、报告解读、寻医导诊、特医特药、全球找药。
- 急救助手 7x24 真人守护，学习娱乐资源提升日常陪伴。
- 尊老管家、家庭医生、视频问诊与长辈模式系统定制。

适配输出：退休员工福利、养老硬件权益、地产/物业适老化解决方案。

### PRESALE006 地产行业健康养老服务方案

结构主线：好房子标准升级 -> 健康服务价值 -> 平安好医生地产行业方案 -> 服务内容与合作方式。

关键模块：

- 地产硬件内卷、楼盘缺少健康和服务营销元素。
- 好房子从物理空间到社区运营，再到医养服务。
- 价值分层：地产能去化、业主享服务、物业有收入。
- 健康地产方案覆盖社区和家庭：家庭医生、健康档案、绿通就医、健康小屋、智能硬件。
- 人群场景：儿童、成人、老人。
- 案例：家庭医生紧急救助、招商成都、天保基建、黄山旅居基地。
- 合作方式覆盖售前、售中、售后，支持购房赠权益、智能硬件、医健权益、家财险。

适配输出：地产集团、物业公司、社区健康运营、楼盘销售赋能方案。

### PRESALE007 联通产品介绍及推广方案

结构主线：平安健康介绍 -> 产品内容 -> 省份案例 -> 推广方案。

关键模块：

- 互联网医疗行业地位、AI 技术、线上+线下服务体系。
- 健康管家会员、7x24 问诊、绿通协助挂号、名医资源。
- 权益使用流程：短信、公众号、实名认证、跳转平安健康小程序/App。
- 省份案例：辽宁、北京、黑龙江、吉林等运营商权益包。
- 推广方案：平安健康 App 端内、抖快微支付宝投流、社区泛渠道、药店推广、套餐联合、软服务+硬件、实物促活。

适配输出：运营商权益包、号卡增值、渠道推广、月卡/合约包方案。

### PRESALE008 企业合作方案 V2

结构主线：公司介绍 -> 服务能力介绍 -> 会员产品介绍 -> 客户案例。

关键模块：

- 平安健康发展历程、用户客群、医生团队、商业模式。
- 四医服务体系：家医、专医、名医、就医协助。
- AI 数字人名医、居家养老能力、供应商管理。
- 会员制健康管理服务与三档会员。
- 案例：硬件厂商血压手表、退休员工智能音箱、运营商权益、合作方 App H5 插件。

适配输出：通用企业合作方案、初次拜访材料、综合能力介绍。

### PRESALE009 智能硬件招商 V2

结构主线：智慧社区健康家 -> 设备数据汇聚 -> 智能音箱中枢 -> 健康档案与干预 -> 跌倒救援案例。

关键模块：

- 居家健康管理由健康设备、安防监测、智能音箱组成。
- IoT 平台汇聚血压、血糖、睡眠、烟雾、水浸、门窗、跌倒等数据。
- 智能音箱连接家庭医生、物业管家、长者和子女。
- 数据链路：监测 -> 建档 -> 评估 -> 干预 -> 改善。
- 独居老人跌倒预警和救援案例。

适配输出：硬件平台招商、地产智能社区、适老化设备方案。

### PRESALE010 联通在线定制产品介绍

结构主线：公司介绍 -> 服务介绍 -> 联通在线定制产品 -> 合作案例和营销政策。

关键模块：

- 管理式医疗+家庭医生会员制+O2O 医疗健康服务。
- 医疗资源、AI 就医、智医数字人、四医服务、购药服务。
- 月卡、年卡、零售就医产品设计和设计思路。
- 合作生态：金融、保险、运营商、日常消费、医疗器械、营养保健。
- 合作案例：中国移动全球通、华为血压手表、慢病管理。
- 营销政策和推广探讨：月卡、家宽融合、健康平台、增值会员包。

适配输出：运营商定制权益、联名健康平台、月卡/年卡/零售就医商业方案。

## 3. 结构复用建议

- 面向企业 HR/工会：优先采用 `PRESALE002 + PRESALE003 + PRESALE008` 的“企业保障/会员/案例”结构。
- 面向运营商：优先采用 `PRESALE007 + PRESALE010` 的“产品包/营销政策/省份案例”结构。
- 面向地产/物业：优先采用 `PRESALE006 + PRESALE009 + PRESALE005` 的“好房子/硬件/养老音箱”结构。
- 面向养老/政企：优先采用 `PRESALE001 + PRESALE005` 的“养老政策/三位一体/护住乐医/硬件入口”结构。
- 面向健康管理产品：优先采用 `PRESALE004 + PRESALE003` 的“痛点/四师共管/产品权益/履约路径”结构。
