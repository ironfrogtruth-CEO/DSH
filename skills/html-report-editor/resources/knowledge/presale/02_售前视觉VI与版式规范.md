# 售前视觉 VI 与版式规范

## 1. 视觉定位

名称：平安好医生售前方案风格。

关键词：

- 专业可信、客户导向、高信息密度。
- 平安橙作为主识别色，白底/浅灰底承载复杂信息。
- 以表格、流程、矩阵、权益卡、手机截图和案例页证明可落地。
- 比业绩发布模板更偏销售交付，信息更密，页面更直接。

与“平安汇报模版”的关系：

- 业绩发布类材料默认采用 `平安汇报模版` 的浅绿蓝、橙绿组合和克制科技感。
- 售前方案类材料默认叠加本规范，强化橙色、客户场景、产品权益、流程表格、App/小程序截图和案例证明。

## 2. 色彩体系

| 用途 | 推荐色值 | 使用方式 |
| --- | --- | --- |
| 平安橙主色 | `#f05a22` / `#f15a24` | 标题、重点数字、流程节点、表头、箭头、强调条。 |
| 深橙/红橙 | `#d94d1f` / `#c83d1a` | 强强调、按钮、深色页局部高亮。 |
| 浅橙底 | `#fff1e8` / `#fdeee8` / `#fdf3f1` | 卡片背景、重点权益底色、模块区分。 |
| 白色纸面 | `#ffffff` / `#fbfbfb` | 大部分内容页底色和表格底色。 |
| 浅灰背景 | `#f5f5f5` / `#f7f7f7` | 分区背景、对比页面、表格隔行。 |
| 线框灰 | `#d9dde3` / `#bfbfbf` | 表格线、卡片边、流程连线。 |
| 正文黑灰 | `#222222` / `#333333` | 正文、说明、表格主文字。 |
| 辅助绿 | `#1d8153` | 健康、增长、服务成效、正向结果。 |
| 深色科技底 | `#111111` / `#1b1b1b` | 仅用于运营商/硬件/AI 科技风页面的局部章节，不作为通用底色。 |

使用规则：

- 售前页默认“白底 + 橙色标题/表头 + 灰色分隔线”。
- 客户行业方案可根据场景加入少量照片或城市图，但不改变平安橙主识别。
- 产品手册和权益表格必须保持可读性，避免用大面积渐变覆盖正文。
- 深色科技页只在 AI、数字人、运营商、硬件招商等页面使用，且文字必须有足够对比。

## 3. 字体与文字层级

默认字体：

```css
font-family: "PingFang SC", "Microsoft YaHei", "Source Han Sans SC", "Noto Sans CJK SC", Arial, sans-serif;
```

层级建议：

| 层级 | 1280x720 建议字号 | 样式 |
| --- | ---: | --- |
| 封面标题 | 42-56px | 粗体，平安橙或深色。 |
| 内容页标题 | 28-36px | 左上，平安橙或黑橙组合。 |
| 章节/目录标题 | 30-42px | `CONTENT/目录` 可用中英混排。 |
| 模块标题 | 18-24px | 粗体，橙色/黑色。 |
| 表格正文 | 11-15px | 紧凑，行高 1.25-1.45。 |
| 卡片正文 | 13-16px | 深灰，关键词橙色加粗。 |
| 注释/免责声明 | 9-11px | 灰色，页脚或表格下方。 |

## 4. 页面版式

### 封面

常见类型：

- 客户方案封面：城市/建筑/客户行业图 + 标题 + 年份。
- 产品手册封面：白底或浅灰底 + 平安橙标题 + 产品名。
- 硬件/AI 封面：深色底 + 橙色科技图形 + 产品名。

规范：

- 第一视口必须出现“平安健康/平安好医生”或产品/客户主题。
- 封面不做大段解释，最多 1-2 行副标题。
- 可使用 `curated_assets.csv` 中的场景照片或横幅素材作为背景/副视觉。

### 目录页

常见结构：

- 左上 `CONTENT/目录`。
- 右侧或中部放 3-4 个章节。
- 当前章节可用橙色，其他章节灰色。
- 大段材料中目录页会多次出现，用作章节分隔。

### 内容页

默认布局：

- 页边距 42-60px。
- 标题在左上，正文主体从 y=110-140px 起。
- 页面下方可放注释、免责声明、页码。
- 信息密度高时优先使用表格/矩阵，不做过大留白。

常见版式：

- 左图右文：用于场景、案例、产品展示。
- 顶部结论 + 下方矩阵：用于产品权益、服务体系。
- 中央流程 + 两侧说明：用于履约路径、服务链路。
- 三列/四列卡片：用于痛点、卖点、权益包。
- 大表格：用于价格、权益明细、FAQ、产品组合。
- 手机截图网格：用于 App/小程序履约说明。

## 5. 常用视觉组件

| 组件 | 视觉样式 | 典型用途 |
| --- | --- | --- |
| 橙色章节条 | 橙底白字或橙色细长条 | 页标题、表头、流程节点。 |
| 权益表格 | 白底、灰线、橙色表头/重点列 | 会员档位、月卡/年卡、补充医疗产品组合。 |
| 服务流程箭头 | 数字圆点/矩形节点 + 橙色连线 | 领取、认证、选择、使用、查询。 |
| 三档产品卡 | 个人/家庭/尊享或银/金/钻三列 | 产品分层和价格说明。 |
| 能力全景图 | 中央能力 + 四周服务模块 | 四医、四师共管、护住乐医、医健品。 |
| 手机截图阵列 | 3-5 张手机界面并排 | 履约路径、权益领取、健康宝使用。 |
| 案例证明页 | 背景/场景图 + 数据指标 + 合作内容 | 中国移动、华为、招商、天保、银行。 |
| 硬件展示卡 | 设备图 + 功能标签 + 服务闭环 | 音箱、手表、检测仪、安防设备。 |
| 免责声明脚注 | 灰色小字，贴近页底 | 服务范围、资质、付费项、数据口径。 |

## 6. 图片使用风格

图片类型：

- 医生/问诊/陪诊/医院场景照片。
- 老人/家庭/适老服务照片。
- 地产/社区/城市建筑照片。
- 手机 App、小程序、H5 页面截图。
- 智能音箱、手表、检测仪、传感器等硬件图。
- 客户案例页面截图和合作效果图。

使用规则：

- 手机截图必须配流程编号或短标签，不能只堆图。
- 医生/老人/家庭照片用于建立信任，不应喧宾夺主。
- 硬件图必须和“数据采集-医生解读-主动干预-线下服务”链路绑定。
- 客户商标、第三方品牌、人物肖像用于外发材料前需确认授权边界。

## 7. 页面禁令

- 不把售前方案做成空泛营销海报。
- 不使用没有数据、流程、产品明细支撑的单句口号页。
- 不把全部内容塞进大段正文，应转成矩阵、表格、流程或卡片。
- 不用大圆角胶囊按钮替代表格和服务节点。
- 不省略等待期、服务范围、付费项、注释和数据口径。
- 不在客户方案中脱离知识库自行编造案例、价格或资源数量。
