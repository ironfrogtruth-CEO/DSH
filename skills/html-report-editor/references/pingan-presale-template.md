# 平安好医生售前方案风格

本参考来自便携售前知识库：

```text
resources/knowledge/presale
```

该知识库解析了 10 份售前交付材料，覆盖企业补充医疗、企康会员、健康宝、养老音箱、地产行业方案、运营商方案、智能硬件招商和通用企业合作方案。

## 1. 调用边界

当生成以下材料时，必须叠加本风格：

- 售前方案、客户合作方案、产品介绍。
- 医疗健康服务产品、互联网化产品、金融协同产品。
- 企业补充医疗、企康会员、健康宝、居家养老、智能硬件、运营商权益包、地产/物业方案。

默认先读：

- `01_售前材料内容结构.md`
- `02_售前视觉VI与版式规范.md`
- `03_样式组件与页面模板.md`
- `05_产品场景与客户方案映射.md`
- `06_HTML编辑器调用规则.md`

素材优先读：

- `curated_assets.csv`
- `curated_assets.json`
- `curated_asset_contact_sheet.jpg`

HTML 材料应优先调用 `resources/pingan-materials/99_索引与说明/html_asset_map.json`。该库已经按平安集团汇报风格完成二次筛选、分类、授权状态标注和 `replacement_group` 映射；旧知识库素材只作为事实追溯与补充来源。

## 2. 叙事结构

通用骨架：

```text
封面 -> 目录 -> 行业背景/客户痛点 -> 平安健康定位 -> 能力体系 -> 产品/权益设计 -> 服务流程/履约路径 -> 场景化方案 -> 合作案例/数据证明 -> 合作模式/商务建议 -> FAQ/附录 -> 感谢页
```

按客户选择：

- 企业 HR/工会：企业痛点 -> 补充医疗/健康委托 -> 企康会员 -> 履约流程 -> FAQ。
- 运营商：公司能力 -> 月卡/年卡/零售就医产品 -> 使用流程 -> 省份案例 -> 营销政策。
- 地产/物业：好房子趋势 -> 业主/物业/地产价值 -> 家庭+社区方案 -> 案例 -> 合作方式。
- 养老/政企：养老政策 -> 三位一体管家 -> 护住乐医 -> 合作机会 -> 产品清单。
- 智能硬件：硬件痛点 -> 设备数据 -> 家医解读 -> 主动干预 -> 案例。
- 健康宝：员工健康痛点 -> 四师共管 -> 产品形态 -> 履约路径 -> 服务权益。

## 3. 视觉语言

- 白底/浅灰底承载复杂信息。
- 平安橙 `#f05a22` 用于标题、表头、流程节点、关键数字和强调条。
- 浅橙 `#fff1e8` 用于权益卡、提示框和重点列。
- 深绿 `#1d8153` 只用于健康、增长、服务效果等正向强调。
- 深色科技底只用于运营商、AI、数字人、智能硬件等局部页面。
- 字体用 `PingFang SC`, `Microsoft YaHei`, `Source Han Sans SC`, `Noto Sans CJK SC`, Arial。

## 5. 素材调用

HTML 默认素材库：

```text
resources/pingan-materials
```

调用规则见：

```text
references/pingan-asset-library.md
```

素材根目录：

```text
resources/pingan-materials
```

优先使用 `curated_assets.csv/json` 的 `asset_category`：

- 移动端/履约截图：App、小程序、权益领取和服务使用流程。
- 智能硬件/设备图：音箱、手表、检测设备、安防传感器。
- 场景照片/插画：封面、行业痛点、医生/老人/家庭服务。
- 图标/Logo：能力模块、流程节点、生态标识。
- 横幅/装饰条：章节页、封面副视觉、橙色强调条。
- 整页/大图版式参考：复杂表格、流程图和整页布局复刻。

输出中要记录 `PRESALE### p##` 或 `PRESALE###_A####`，便于追溯。

## 6. 禁令

- 不编造客户案例、价格、服务次数、资源数量、等待期。
- 不省略服务范围、付费项、免责声明和数据口径。
- 不把售前方案做成只有口号的营销页。
- 客户商标、第三方品牌、人物肖像外发前需提示授权风险。
