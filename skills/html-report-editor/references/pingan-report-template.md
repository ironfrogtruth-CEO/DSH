# 平安汇报模版设计语言

本参考由本地 `PPT模版` 下三份 PDF 提取整理，并已固化为便携规则：

- `1765445073932_2025年中期业绩发布.pdf`，24 页。
- `1765446517049_2024年度业绩发布.pdf`，20 页。
- `1774446665534_平安健康医疗科技有限公司 2025 年业绩发布.pdf`，25 页。

三份 PDF 均为 16:9，页面尺寸 960 x 540 pt。生成 HTML 汇报材料时仍使用 1280 x 720 px，但设计比例、留白和组件关系按该模版执行。

## 1. 视觉定位

名称：平安汇报模版。

适用：

- 经营业绩发布
- 领导层汇报
- 战略进展汇报
- 产品方案与业务进展材料
- 医疗健康服务、互联网化产品、金融协同方案

关键词：

- 专业、克制、高信息密度
- 医疗健康科技感
- 平安橙作为标题和关键强调
- 深绿作为经营增长、正向指标、业务能力强调
- 白底薄线卡片承载复杂结构
- 浅绿蓝背景形成统一品牌感

## 2. 色彩体系

从 PDF 页面抽取到的高频颜色：

| 用途 | 色值 | 说明 |
| --- | --- | --- |
| 平安橙 | `#f05a22` | 标题、关键数字、页眉强调、箭头、图标、按钮。 |
| 深绿 | `#1d8153` | 增长指标、业务亮点、正向结果、协同/赋能模块。 |
| 浅蓝底 | `#eaf5fb` | 封面、章节页、感谢页常见背景。 |
| 浅绿白 | `#f5faf4` | 内容页大面积背景。 |
| 线框灰 | `#bfbfbf` | 卡片边框、分隔线、图表辅助线。 |
| 中性灰 | `#666666` | 公司名、说明文字、页脚、注释。 |
| 淡橙底 | `#fdeee8` / `#fdd9c2` | 橙色标签、提示框、局部底色。 |

使用规则：

- 每页主标题优先使用平安橙。
- 业务增长、正向结论、能力沉淀使用深绿。
- 橙色与绿色不要平均分配：橙色做方向与强调，绿色做成果与能力。
- 背景必须浅，不使用大面积深色底。
- 图表灰柱、橙柱、绿柱组合优先于多彩调色盘。

## 3. 背景与页眉页脚

内容页背景：

- 白到浅绿蓝的低对比渐变。
- 底部右侧有淡绿色波纹/地形线。
- 底部有浅蓝点阵科技网格。
- 右侧边缘有竖向浅灰点阵。
- 右上或右边缘有一条短平安橙竖条。

页脚：

- 左下角放注释，字号 10-12px，颜色中性灰。
- 右下角放页码，字号 14-16px，颜色中性灰。
- 页脚不使用粗线，不干扰主体。

## 4. 字体与标题

标题风格：

- 中文主标题使用近似楷体/手写标题风格，推荐 `KaiTi`, `STKaiti`, `FZKai-Z03S` 作为标题 fallback。
- 标题色为平安橙。
- 标题位于左上，横向展开，避免居中大标题。
- 标题字号在 1280×720 页面中建议 30-38px。

正文风格：

- 正文以黑色/深灰为主，局部关键词使用橙色或绿色。
- 表格、卡片、注释保持紧凑。
- 每页内容密度较高，不能做成营销海报式大留白。

字号建议：

| 层级 | 字号 |
| --- | ---: |
| 封面标题 | 48-62px |
| 内容页主标题 | 30-38px |
| 分区标题 | 20-28px |
| 卡片标题 | 18-24px |
| 正文 | 15-19px |
| 注释/页脚 | 10-12px |
| 关键数字 | 28-42px |

## 5. 典型页面类型

### 封面

结构：

- 左上角公司中文名、英文名、上市主体说明。
- 左中大号平安橙标题，如“2025年业绩发布”。
- 右中或右下放大型 A 形品牌视觉。
- 左下角放股份代号。
- 背景为浅蓝天空/城市/波纹线。

HTML 生成时若无 3D A 资产，可用 CSS 生成大型渐变 A 形占位，但不要用普通圆形插画替代。

### 目录页

结构：

- 左上“目录”平安橙小标题。
- 中部纵向 01/02/03 三段目录。
- 当前章节可用黑色，其余章节灰色。
- 编号用橙色或绿色交替。
- 右侧保留橙色竖条和点阵。

### 战略全景页

结构：

- 顶部平安橙标题。
- 中央用框架图表达“价值主张-商业模式-科技赋能”。
- 左右对称，中央放品牌/核心平台。
- 使用薄线框、浅灰底、橙色关键词。
- 底部可放科技赋能底座。

### KPI/业绩总结页

结构：

- 顶部标题。
- 主体用 3-4 个竖向卡片或指标卡。
- 每个卡片上方放图标，中部放指标和同比，底部放说明。
- 关键数字用橙色或绿色。
- 保持白底卡片、薄边框、轻阴影或无阴影。

### 左右分栏页

结构：

- 左侧为业务模式、流程、产品体系或图表。
- 右侧为“亮点”栏，放 2-3 个大指标盒。
- 中间可用竖向虚线分隔。
- 右侧亮点卡片通常为白底灰边，数字用深绿。

### 图表页

结构：

- 以灰柱为基底，橙色强调当期或关键变化，绿色强调增长或正向能力。
- 图表旁放小结论框，不只放图。
- 底部可放一句结论条。
- 每个图表保持标题、单位、注释完整。

### ESG/活动页

结构：

- 左侧可用图片矩阵，右侧用绿色栏标题和要点列表。
- 绿色横条承载 ESG 亮点标题。
- 图片必须排版整齐，有橙色小标题。

### 感谢页

结构：

- 左上公司名和英文名。
- 左中大号 `THANKS`，平安橙。
- 右下放 A 形品牌视觉。
- 左下放股份代号。

## 6. 组件规则

卡片：

- 白底。
- 1px 灰边框。
- 半径 0-4px，避免圆润卡片。
- 内边距 14-22px。
- 可使用橙色或绿色顶栏。

标签：

- 橙色标签表示方向、场景、行动。
- 绿色标签表示能力、成果、增长。
- 标签宜为矩形或轻微圆角，不做胶囊按钮。

箭头：

- 推荐使用双箭头或并列 chevron：绿色 + 橙色。
- 用于从主流程指向亮点、从能力指向结果。

图标：

- 使用线性或实心医疗/金融/企业图标。
- 图标色优先橙色或绿色。
- 不使用多彩插画风。

表格：

- 表头可用橙色或绿色底。
- 行分隔线轻。
- 文字紧凑。
- 重要列用浅橙/浅绿底色。

## 7. 页面布局比例

内容页建议：

- 页面边距：48-64px。
- 主标题顶边距：36-50px。
- 主体内容上边距：110-145px。
- 页脚注释 y 坐标：680px 左右。
- 页码 x 坐标：1240px 左右，y 坐标：680px 左右。
- 右侧亮点栏宽度：230-270px。
- 中央主体区宽度：850-980px。

## 8. 生成禁令

- 不要使用深色大背景。
- 不要做彩虹渐变。
- 不要把页面做成网页 landing page。
- 不要使用大圆角卡片和漂浮装饰球。
- 不要用大量插画稀释信息密度。
- 不要把所有内容都装进卡片；战略全景和流程图应使用框架图。
- 不要省略注释、单位、口径和页码。
