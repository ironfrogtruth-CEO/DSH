# 企业健康报告杂志skill v1.3

这是一个面向企业健康报告的 A4 杂志式 HTML skill，用于把企业健康数据、行业职业健康知识库、公共健康知识和平安健康服务知识库转化为可编辑、可导出、可校验的报告。

## 快速使用

1. 先读取企业健康数据、企业公开资料、行业职业健康风险包和服务知识库。
2. 按“同一报告骨架 + 企业差异化叙事重心”形成页面内容，正文面向目标企业 HR、工会和管理层。
3. 执行固定画布 HTML 生成：

```bash
python tools/render_from_spec.py resources/a4_demo_spec.json templates/magazine-editor-template.html output.html
```

4. 用浏览器打开 `output.html`。
5. 点击“开启编辑”。
6. 可编辑文字、拖动缩放模块、替换顶部图/页脚图/背景图、插入文字/图片、调整图层透明度。
7. 点击“导出PDF”使用浏览器打印为 PDF。

## 设计取舍

- 能力完整，但界面克制。
- 复杂控制不放到常驻工具栏，而放到选中组件后的属性面板。
- 企业健康报告默认采用 A4 固定画布，不参与浏览器自适应。
- 普通页顶部图层固定 300px，页脚图层固定 200px；二者是独立图层，并支持上下渐变透明度。
- 8 家企业可以共用报告骨架，但必须根据委托消耗率、就医服务与日常健康支持结构、年龄结构、行业风险包和商品信号形成不同主线。
- 商品和服务使用数据写成员工健康需求信号，服务建议写成企业可组织的健康工作动作和年度复盘材料。

## 注意

- 不得出现提示词型文案、供应商运营话术、素材来源表述、右上角固定署名和右下角页码。
- 对客正文不直接使用“院内/院外消费”；改写为“就医相关支出 / 医疗机构服务”和“日常健康支持支出 / 健康管理与药械补给服务”。
- 对客正文不直接使用“6+1”；改写为“七项就医与健康支持服务”，并写清挂号预约、体检/筛查、床位协调、手术/专科协助、陪诊、药品服务、家庭医生。
- 金额字段不保留小数点后两位，订单均值也按整数元展示。
- “判断”类模块必须写成明确提醒或企业侧动作，不用一段总结替代结论。
- 小数比例字段必须正确换算为百分比，例如 `0.4` 展示为 `40%`。
- 静态 QA、DOM 溢出/重叠 QA、PDF/打印 QA 是交付闸门；失败必须回退修正。
