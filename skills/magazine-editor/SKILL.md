# 企业健康报告杂志skill v1.3

## 定位

本 skill 沉淀 **企业健康报告内容设计方法 + A4 杂志式 HTML 编辑器底座**。它不是普通网页生成器，也不是简单套模板；它用于把企业健康数据、企业公开资料、行业职业健康知识库和平安健康服务知识库转化为可编辑、可导出、可校验的企业健康报告。

适用产物：

- A4 杂志版报告，每页固定 A4 画布
- HR、工会、管理层阅读的企业健康治理报告
- 需要“像报告一样浏览、像组件一样编辑、像画布一样导出”的 HTML 材料

默认不再把 16:9 作为企业健康报告首选画布；除非用户明确要求横版汇报，企业健康报告一律优先 A4 杂志版。

## 核心原则

1. **固定画布**：每页是独立固定尺寸画布，不使用浏览器流式排版。
2. **界面克制**：默认浏览态只展示报告；编辑模式开启后才显示极简工具栏。
3. **能力完整**：文字、图片、顶部图、页脚图、背景图、组件、图层均可编辑。
4. **属性后置**：字体、字号、颜色、透明度、图层顺序等放在选中组件后的属性面板，不常驻铺满页面。
5. **导出稳定**：PDF/打印时隐藏工具栏、属性面板、选中框、拖拽手柄，按固定画布分页。
6. **读者优先**：报告正文站在目标企业 HR、工会、管理层视角，表达职工健康、组织关怀、健康职场建设和年度复盘成果。
7. **事实基座**：先调用企业健康数据、企业公开资料、行业职业健康知识库、公共健康知识和平安健康服务知识库；不得用主观臆断替代知识库。
8. **差异叙事**：8 家企业可以共享报告骨架和治理逻辑，但不得共享同一故事线。必须按委托消耗率、就医服务与日常健康支持结构、年龄结构、行业风险包、商品信号形成企业个性化主线。
9. **客户视角**：正文默认服务目标企业年度健康工作，不写“我们要促使用、促消耗、做转化”。健康服务建议必须落到企业可组织的动作、可沉淀的材料和可汇报的成果。

## 支持画布

| canvas_type | 尺寸 | 用途 |
|---|---:|---|
| `a4` | 794 × 1123 px | A4 杂志报告、打印版年度报告 |
| `16x9` | 1280 × 720 px | 横版汇报材料、投屏展示材料 |

企业健康报告默认使用 `a4`。

## 企业健康报告内容骨架

参考已验证蓝本 `中移互联网有限公司_读者视角蓝本.html`，企业健康报告默认 10 页：

1. **封面**：企业名称、年度职工健康服务复盘、4 个关键指标。
2. **年度健康治理成果**：覆盖基础、入口触达、结构重点、年度工作判断。
3. **企业画像与员工结构**：行业公开信息、年龄性别结构、岗位场景推断、画像结论。
4. **年度服务与资金盘点**：可用权益、使用金额、使用人数、委托消耗率、就医服务与日常健康支持结构。
5. **三条健康风险主线**：按企业行业和数据生成，不固定为同一套疾病叙事。
6. **行业职业健康防范**：职业病危害因素、职业相关健康风险、防范措施和企业侧工作动作。
7. **委托商品与健康需求信号**：TOP 商品解释为员工健康需求，不写成销售或促消耗。
8. **服务组织建议**：筛查、解读、主动干预、便捷就医、后续跟踪，结合平安健康服务知识库。
9. **五项协同行动**：定制服务方案、平安圈服务保供、方案宣导与七项就医健康服务说明、App 激活、首次到企活动。
10. **年度节奏与公开参考**：季度推进、年度主线、公开来源引用。

## 企业差异化分型规则

每家企业必须至少按以下 5 个维度形成个性化叙事：

| 维度 | 用法 |
|---|---|
| 委托消耗率 | 高消耗写“权益使用基础较好、服务提质”；低消耗写“参与覆盖需提升、入口宣导和活动组织优先”。 |
| 就医服务与日常健康支持结构 | 就医相关支出高写“就医协助、复诊、慢病管理”；日常健康支持高写“健康补给、常用药械、家庭药箱和门店服务”。 |
| 年龄结构 | 中青年高写“久坐代谢、睡眠压力、职业疲劳”；中高龄高写“慢病、心脑血管、复诊用药”。 |
| 行业风险包 | 互联网/投资/总部写办公工效与压力；港口/物流/轨交/汽车/水利写职业暴露、倒班、粉尘噪声、高温、外业或实验检测。 |
| 商品信号 | 呼吸机映射睡眠呼吸；血压计/血糖仪映射慢病监测；钙/氨糖/健腰映射肌骨骨骼；阿胶/西洋参/气血映射疲劳恢复与中医调理。 |

结论：**可以共用报告骨架，不可共用同一故事线。**

## 内容禁令

报告正文不得出现：

- “面向 HR/工会”“服务不宜平铺”“报告要……”“管理层可看到……”等提示词型文案。
- “高频服务转化”“促消耗”“复购提醒”“爆品推销”“GMV”“客单”“供应商视角”等商业运营话术。
- “用户上传的截图”“OCR”“图片识别”等素材来源或制作过程表述。
- 每页右上角“平安集团健康服务支持”固定署名。
- 右下角页码。
- “具备承接条件”“年度留痕材料”“治理闭环”“把……串成……”等制作痕迹或空泛管理话术；改用“员工使用路径已初步建立”“年度工作成果沉淀”“筛查、解读、干预、就医和随访”“结合……建议将……作为年度健康主题”等客户可读表达。

字段表达替换：

| 数据字段或旧表达 | 对客表达 |
|---|---|
| 院内消费 / 院内结构 | 就医相关支出 / 医疗机构服务 |
| 院外消费 / 院外结构 | 日常健康支持支出 / 健康管理与药械补给服务 |
| 高频服务转化 | 提高员工服务参与覆盖 |
| 复购提醒 | 持续健康支持 / 员工健康需求跟进 |
| 拉动 GMV / 促消耗 | 提升权益有效使用 / 形成年度健康服务成果 |
| 运营抓手 | 年度工作抓手 / 企业侧推进事项 |
| 年度留痕材料 | 年度工作成果沉淀 / 年度复盘材料 |

金额展示规则：

- 面向客户的金额一律不保留小数点后两位；万元、元等金额字段展示为整数，保留单位。
- 比例字段继续按百分比展示，允许保留一位小数用于结构占比，但委托消耗率不得写成小数百分比。
- 订单均值属于金额，也按整数元展示。

客户可读概念定义：

| 内部简称 | 对客定义 |
|---|---|
| 6+1 | 不直接使用该简称；改写为“七项就医与健康支持服务”。 |
| 号 | 挂号预约：协助员工预约合适门诊或专家号源。 |
| 检 | 体检/筛查：组织健康检查、专项筛查和报告解读。 |
| 床 | 床位协调：在权益范围内协助住院床位安排。 |
| 刀 | 手术/专科协助：协助对接手术或专科诊疗资源。 |
| 陪 | 就医陪诊：为就医流程提供陪同和协助。 |
| 药 | 药品服务：常用药、慢病用药、用药咨询和药品配送。 |
| 家医 | 家庭医生：提供日常问诊、健康档案、指标解读和随访建议。 |

## 客户视角故事线

企业健康报告必须按以下逻辑组织内容，且每家公司按自己的数据和行业重排重点：

```text
企业行业场景 + 员工结构 + 权益使用 + 商品/服务信号
→ 年度健康主题
→ 服务组织建议
→ 企业协同行动
→ 年度复盘成果
```

页面之间必须存在“输入数据 → 客户问题 → 页面结论 → 下一页延续”的递进关系：

| 页码 | 页面结论方向 |
|---|---|
| 1 | 这是年度职工健康服务复盘，不是供应商服务清单。 |
| 2 | 从服务配置转向员工健康治理成果。 |
| 3 | 员工结构和工作场景决定下一年度健康主题。 |
| 4 | 入口已有基础，实际参与覆盖需要主题和组织动作牵引。 |
| 5 | 说明风险来自哪里、为什么要管、下一步怎样干预。 |
| 6 | 行业职业健康防范要日常化、组织化。 |
| 7 | 员工主动选择的健康商品反映真实健康需求。 |
| 8 | 服务建议必须逐项回到数据、行业场景、商品信号和公共健康知识。 |
| 9 | 五项协同动作把年度健康服务拆成企业可配合的清晰节点。 |
| 10 | 从合作启动到年度复盘，形成可追踪的年度工作节奏。 |

页面结论写法：

- “判断”类模块必须用“提醒事项 / 下一步提醒 / 企业侧动作”这类明确标题，不用一段总结替代结论。
- 不使用“组织口径”作为正文标题；改为“企业侧怎么做”“企业侧年度动作”“企业侧管理动作”等客户能理解的表达。
- 每个提醒必须包含可执行方向，例如“优先确认年度主题”“组织重点人群报名”“把筛查结果纳入年度复盘材料”。
- 不把“企业做什么”“产出什么”这类解释语写进报告正文；正文标题改为“年度重点工作”“年度复盘材料”等正式表达，具体内容用动作和材料名称说清楚。
- 首页不放 4 块核心数据卡。封面只保留报告定位、企业名称、年度导语和视觉背景。
- A4 打印版面向领导阅读，正文和列表字号不得过小；普通卡片正文建议不低于 14px，重点结论建议不低于 17px，引用可略小但仍需清晰可读。字号放大后必须重新执行溢出和重叠 QA。

委托消耗率等小数字段必须按比例展示：`0.4` 展示为 `40%`，`0.45` 展示为 `45%`，不得写成 `0.4%`。

## 顶部图 / 页脚图规则

顶部图、页脚图不是背景图，必须是独立可选中图层。

必须支持：

- 选中
- 替换图片
- 拖动 / 缩放
- 图层上移 / 下移 / 置顶 / 置底
- 上透明度 / 下透明度，形成由上到下的渐变透明度

默认尺寸建议：

| 画布 | 普通页顶部图 | 普通页页脚图 | 封面顶部图 | 封面页脚图 |
|---|---:|---:|---:|---:|
| A4 企业健康报告 | 220 px | 300 px | 以封面全幅背景处理 | 以封面全幅背景处理 |
| 16:9 | 80–120 px | 56–90 px | 170–240 px | 80–120 px |

A4 企业健康报告普通页顶部图层高度必须为 220px，页脚图层能力保留为 300px 可编辑图层。普通页不强制显示页脚图；内容铺满或左下角注释区启用时，应隐藏页脚图但保留插入、替换、裁剪和透明度编辑能力。二者均为可选中、可替换、可拖拽缩放、可设置上下透明度的独立图层。背景图片本身不要写死透明度，应通过编辑器的上下线性透明度能力控制。

除首页和尾页外，核心页面内容必须占据 A4 画布高度的 75% 以上。普通页术语注释统一放在左下角固定注释区，最后一行坐标保持一致。报告解读框保持浅橙纸质视觉和“解读”短标签，其他业务模块框弱化边框和阴影，不与解读框抢视觉层级。若报告解读框使用医生阅读报告图片，图片固定在右侧且各页宽度一致，不得用压缩图片解决版面拥挤；五个同类服务卡优先按 3+2 两行均衡铺满。

## 组件类型

- `text`：文字模块，内容可编辑
- `image`：图片模块，双击替换图片
- `shape`：普通图形/卡片/数据图形容器，可拖动缩放删除
- `top`：顶部图层
- `footer`：页脚图层
- `background`：页面背景层

## 生成流程

```text
企业健康数据 + 企业公开资料 + 行业职业健康知识库 + 平安健康服务知识库
→ 数据口径校验
→ 企业差异化叙事分型
→ 10页 A4 内容编排
→ 生成独立背景素材
→ 注入可编辑 HTML 组件
→ 生成固定画布 HTML
→ 静态结构 QA
→ 浏览器渲染 QA
→ PDF/打印 QA
→ 交付 HTML + 背景素材 + QA 记录
```

## QA 闸门

交付前必须检查：

| 检查项 | 标准 |
|---|---|
| 固定画布 | 每页宽高固定，非流式排版 |
| 编辑器轻量 | 默认只看报告，编辑模式才显示工具 |
| 组件编辑 | 文字/图片/模块可拖动缩放删除 |
| 顶部图/页脚图 | 独立图层，可替换，可调上下渐变透明度 |
| 属性面板 | 选中后出现，不常驻遮挡页面 |
| PDF导出 | 无工具栏、无手柄、无漂移、无多余空白页 |
| 代码结构 | 不临时重写编辑器核心能力，只注入页面spec |
| A4 图层尺寸 | 普通页顶部图 300px，页脚图 200px |
| 禁用文案 | 无提示词型文案、无供应商运营话术、无素材来源表述 |
| 口径换算 | 小数比例字段正确展示为百分比 |
| 布局完整 | DOM 检查无文字溢出、无组件重叠 |
| 引用来源 | 只列公开知识库/公共来源，不引用 Excel 或本地截图 |

QA 是闸门：任何一项失败必须回退到内容结构、组件高度或生成脚本，不能直接交付。

新增客户视角 QA：

- 每页必须有客户问题和页面结论，不能只是数据展示。
- 每条风险必须写清形成路径、数据提示和干预方向。
- 每项服务建议必须能追溯到前文的数据、行业、商品信号或公共健康来源。
- 正文不得出现提示词型说明和供应商经营指标。
- 文风优先采用央国企、工会和职工关怀语境。
