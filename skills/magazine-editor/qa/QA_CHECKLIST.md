# QA CHECKLIST

## 结构检查

- [ ] 每页是否使用固定画布尺寸
- [ ] A4 是否为 794 × 1123 px
- [ ] 16:9 是否为 1280 × 720 px
- [ ] 页面是否使用绝对定位组件
- [ ] 是否没有浏览器流式排版影响正文布局

## 编辑器检查

- [ ] 默认浏览态是否不显示属性面板
- [ ] 编辑模式开启后是否出现极简顶部工具栏
- [ ] 工具栏是否只包含：编辑开关、插入文字、插入图片、替换顶部图、替换页脚图、背景图、保存HTML、导出PDF
- [ ] 选中组件后属性面板是否出现
- [ ] 属性面板是否支持字体、字号、颜色、加粗、对齐、透明度、层级调整、删除

## 图层检查

- [ ] 顶部图是否为独立图层
- [ ] 页脚图是否为独立图层
- [ ] 顶部图/页脚图是否可选中
- [ ] 顶部图/页脚图是否可替换
- [ ] 顶部图/页脚图是否支持上透明度/下透明度
- [ ] 背景图是否独立于顶部图/页脚图

## 组件检查

- [ ] 文本组件是否可编辑
- [ ] 图片组件是否可双击替换
- [ ] 组件是否可拖动
- [ ] 组件是否可缩放
- [ ] 组件是否可删除
- [ ] 组件是否不会遮挡自身内容

## 导出检查

- [ ] PDF/打印时是否隐藏工具栏
- [ ] PDF/打印时是否隐藏属性面板
- [ ] PDF/打印时是否隐藏拖拽/缩放手柄
- [ ] PDF是否按页分页
- [ ] PDF是否无漂移、无多余空白页
