# 企业健康报告文案精修

## 本地化来源与使用边界

本 Skill 在项目内独立运行，不调用第三方“去 AI”服务，也不依赖 Codex。规则来源经过企业报告场景重写：

- `blader/humanizer`（MIT）：吸收事实保真、删除模板化元话语、避免虚构引用与含糊归因的检查方法；
- `stephenturner/skill-deslop`（MIT）：吸收直接性、节奏、可信度、真实感、信息密度五维审校；
- `redbaronyyyyy-eng/humanizer-zh-academic`（MIT）：只参考中文连接词、机械排比和抽象名词堆叠的识别，不采用学术论文口吻，不以规避检测器为目标。

详细来源与改写边界见`references/provenance.md`，中文模式清单见`references/anti-ai-patterns-zh.md`。生产时由 A08 把本文件正文注入 DeepSeek `localSkillContext`；模型只改表达，事实裁决仍由现有来源与闸门完成。

## 不可变更项

保持企业名、年度、数字、单位、正负方向、字段来源、`sourceId`、服务/商品准确名称、推荐决策、组件 ID 和页面任务。逐条执行 A04 传入的 `sourceBoundaries[]` 与 `blockedClaims[]`；无来源内容不补写。

## 改写方法

1. 先写读者能直接理解的判断，再补必要的专业词。
2. 一段只讲一个判断，优先短句；用“数据说明什么、对管理意味着什么、接下来怎么做”组织。
3. 删除流程说明、字段解释、重复数字、空泛小结和模板套话。
4. 禁用虚高、生造焦虑或承诺疗效的表达；不自造服务名或管理概念。
5. 注释只解释口径、公式、阈值或冷门术语，不重复正文结论。
6. 每个详情页标题必须保留一个逐字来自`pageTask`且同时出现在标题中的2至12字主题锚点，并以`titleBasis.taskAnchor`返回。若模型返回的锚点过长、缺失或不在标题中，本地A08只能从锁定的`pageTask`与当前标题交集确定性收口；不得为修复元数据新增事实。
7. 标题出现`三类`、`四项`、`六步`等明确数量词时，副标题必须用`｜`逐项列出对应内容，项目数与标题完全一致。此时逐项列举优先于副标题数字证据要求，人数、金额和比例放回数据组件。
8. 解读先直接概括“本页数据说明什么”，再写企业下一步怎么做、谁负责或怎么看完成。如果图表、卡片和核心判断没有说明行动原因，解读正文必须补清原因。
9. 客户可见标签要随页面内容变化，使用`高龄员工是当前重点`、`住院是主要资金压力`、`服务要跟到就医结果`等直接结论；不得连续套用`为什么……/怎么……`问句，也禁用`管理判断`、`费用判断`、`资金判断`、`配置原则`、`管理边界`、`落地要求`、`服务触达`、`结果回收`等内部工作词。
10. 相邻页面的解读必须分别对应本页证据和页面任务。只替换疾病、人群或服务名称但保留同一套句式，视为模板化失败。
11. 按五个维度复核：是否直接回答本页问题；句长和句式是否有真实信息节奏；判断是否有同页证据；是否像业务人员在说清事情；每句话是否增加新信息。任一维度不合格时，只改对应句子，不整页换一套套话。
12. 删除“背景—挑战—方案—价值”机械框架、连续三段式排比、空泛归因、重复总结、虚假引用、宣传式收束和无证据的“显著/全面/有效”。不得用口语梗、错别字、虚构经历或故意语病制造所谓“人味”。
13. 当 A03 已核验国家政策或诊疗指南时，只写来源明确的适用对象、筛查项目和医生判断边界；不得把公共政策改写成企业员工的强制要求。女性“两癌”方案中的 35—64 岁筛查对象、乳腺体检/彩超/乳腺 X 线等内容，应放在肿瘤或女性筛查同页，并直接连接到筛查、复查和就医服务；宫腔镜不作为常规筛查项目，是否检查由医生根据异常出血或影像异常判断。
14. 标题为“推荐服务”或“服务推荐”时，卡片标题先写可采购的服务名称，正文再写对应风险、适用人群和验收结果；不得用“三高”“心脑血管”“肿瘤”等风险分类替代服务标题。商品区按健康服务、器械、营养支持、药品承接分别表达：器械用于居家记录，营养品只作日常支持，药品只通过药师咨询或复诊购药承接，不直接指定购买。

## 事实边界

- 员工总人数只是企业人群基数，不得写成服务覆盖人数或健康管理覆盖面。
- 有效问卷、有效评价和满意率只代表对应样本，不得外推员工需求、匹配度、参与度或整体认可。
- 个人支付和商城购买记录只说明已经发生支付或使用，不得推断付费意愿或消费活跃。
- 未转线下结案只说明结案路径，不得写成有效分流、减少就医或替代门诊。
- 通用问诊、到企、商城和其他服务使用量，不得与具体风险人群拼接成“已经获得服务”的结论。
- 服务和管理动作不得写成避免疾病事件、避免延误就医、改善健康、减少就诊、缩短等待、优化住院天数、提升理赔效率、降低费用或理赔等结果。
- 没有同口径比较证据，不写“最需要、范围最广、最高、主要入口、高参与度、较高、明显、活跃、较大比例”等强判断。
- `sourceBoundaries[]` 或 `blockedClaims[]` 标记为模拟、估算、推算、未核验或不得进入正式报告的字段，必须从全部客户可见文字和强调计划中删除。

## 页面强调产物

- `emphasisPlan.numbers`：需放大的关键数字，必须绑定同页证据。
- `emphasisPlan.keywords`：解读框中应强调的关键词，不改变句子意义。
- `pageFullnessAssessment`：按实际可见文字和组件评估；只有页面决策为 `add` 或 `roll_up` 且确实绑定推荐对象时，推荐区才计入丰满度。推荐内容不得替代本页证据、数据组件或解读。内容不足时回退 A07 补足有证据的信息，不通过拉伸组件补版。

输出必须通过事实保真、引用保真、术语、语义边界和跨页重复闸门；提示词仍以清晰、无重复为目标。任一事实或语义边界问题未消除时，A08 必须失败并回退返修，不能进入 A09。仅当事实正确、语义清楚、页面任务不同且不涉及标题时，本地审核可将整份报告最多2处轻微表达重复记为`PASS_WITH_WARNING`并继续，不为这类小问题再次调用模型。
