# 记忆更新协议

## 记忆目标

检视宝需要越用越贴合用户的管理偏好。记忆只记录偏好、反馈和稳定规则，不记录不必要的敏感材料正文。

## 首次初始化记忆

首次调用时必须收集：

- 重点关注项：事实可靠性、逻辑合理性、可执行性、组织边界、风险合规、表达质量、其他。
- 回复风格：简洁直接、稳健正式、强势推动、留有余地。
- 是否偏好强批判、温和修改、直接可发、先结论后安排等输出方式。

建议记忆格式：

```json
{
  "event": "initial_preferences",
  "focus": ["事实可靠性", "组织边界", "可执行性"],
  "style": "稳健正式",
  "notes": "用户希望先判断能不能发，再给对上回复和对下安排。"
}
```

## 使用中更新

当用户说“这个风格以后都这样”“记住”“以后重点看...”或明确评价某版回复好/不好时，更新记忆。

记录内容：

- 用户认可的回复风格。
- 用户不喜欢的表达方式。
- 常用审批/回复习惯。
- 用户对部门边界、风险、错别字、任务安排的关注优先级。

不要记录：

- 未脱敏的客户敏感数据。
- 完整材料原文。
- 身份证、手机号、个人健康隐私等敏感信息。

## 平台支持

- 如果平台有内置记忆：写入平台记忆。
- 如果平台允许本地写入：可用 `scripts/update_memory.py` 追加到本地 JSONL 文件。
- 如果平台不允许记忆：在本轮对话中应用偏好，并在结尾提示用户可在平台设置中开启记忆或把偏好作为固定系统提示。

## 每次结尾

代码框后必须询问：

```text
这版回复是否符合您的预期？如需调整，我可以按您的偏好继续优化，并把有效反馈写入检视宝记忆。
```
