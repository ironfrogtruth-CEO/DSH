# 受众、载体与词性路由

## 判断原则

词性会影响一段话的重心，但“自然”不等于某种固定比例。现代汉语中，同一个词也可能在不同语境承担不同功能。可靠的用法是：先确认读者和载体，再判断当前句子要完成什么任务，最后选择更合适的词类与句法骨架。

路由顺序：`载体 → 受众 → 句子任务 → 事实与语气复核`。

- 载体决定信息密度和基本结构。
- 受众决定称谓、知识前提、正式程度和行动距离。
- 句子任务决定主干。标题、数据证据、原因解释、行动建议、风险边界和叙事过渡不能共用一个模板。
- 词性只提供表达重心，不直接生成结论，也不改变受保护事实。

机器可读规则见 `pos-routing-profiles.json`。运行 `scripts/resolve_expression_profile.py --carrier ... --audience ... --clause-role ...` 可以得到组合结果。

## 十二类词性的基本职责

| 词性 | 在专业表达中的主要职责 | 常见风险 |
|---|---|---|
| 名词 | 指明人、事、物、概念和业务对象 | 抽象名词连续堆叠，句子没有动作 |
| 动词 | 写清判断、变化、动作和结果 | 用“开展、推动、打造”等空壳动词代替真实动作 |
| 形容词 | 说明可验证的性质和状态 | “高质量、全面、显著”没有标准 |
| 数词 | 锁定数量、时间、比例和顺序 | 数字有了，口径、对象或意义没有写清 |
| 量词 | 说明统计单位、动作次数和对象规模 | 省略单位，导致数字含义不清 |
| 代词 | 建立说话人与读者的关系，避免重复 | “其、该、这”找不到明确所指 |
| 副词 | 表示时间、范围、程度、否定和判断强度 | “持续、进一步、全面”密集出现，用语气代替证据 |
| 介词 | 建立对象、依据、条件和范围关系 | “基于、围绕、通过、针对”层层套叠 |
| 连词 | 明确因果、转折、条件和并列 | 每句都靠连接词起头，形成翻译式逻辑链 |
| 助词 | 调整结构、时态和语气 | 正式材料中过多语气助词显得拖沓或失准 |
| 叹词 | 表达即时情绪和互动反应 | 进入正式结论后削弱可信度 |
| 拟声词 | 呈现场景声音和叙事质感 | 用于报告、数据结论时制造不必要的表演感 |

## 五类载体

### 邮件

主干用“称谓或责任主体 + 动词 + 对象 + 时间/结果”。任务邮件优先名词、动词、时间副词和必要代词；连词只保留真实关系。对领导先写需要判断的结论，对下属写清责任人、动作、期限和验收条件，对同事保留协商语气。

### PPT

标题优先“对象名词 + 判断或动作动词 + 结果”，数据标签优先“数词 + 量词 + 名词”，行动项优先“主体 + 时间副词 + 动词 + 对象”。少用介词开头的长标题，也不要把所有页面都写成相同节奏。

### 文章

以名词、动词构成叙述主干，按受众和题材适量使用代词、形容词、副词、助词、叹词和拟声词。公众号文章可以用“你、我们”建立关系，小说和诗歌可以调动节奏、意象和声音；这些手法不能直接搬进正式报告。

### 数据分析报告

以对象名词、数词、量词和具体动词锁定样本、变化、比较和结果；因果、转折和限制使用明确连词。少用无指标支撑的形容词、副词，不用叹词和拟声词，不用模糊代词替代指标或群体。

### 企业健康报告

以人群、岗位、风险、服务等具体名词为对象，用数词、量词固定口径，用动词写清发现、影响和服务动作。对企业客户保持正式、可读和可执行；医学、保险和服务边界由真源与领域合同负责。标题、图表、建议和风险提示分别路由，不能整篇套用一种句式。

## 六类受众

- 公众号读者：允许适量“你、我们”和生活化动词；专业词先解释。叹词、助词只在品牌语气确有需要时使用。
- 企业客户：写明企业、员工、岗位、服务和责任主体；少用模糊代词，形容词必须能由标准或证据支撑。
- 领导：先给判断、影响和需要决定的动作；保留数字、时间、责任主体，压缩铺垫。
- C端用户：用“你”或明确用户角色直接说明发生了什么、可以做什么；减少术语和多层连词。
- 下属：写清谁在什么时间完成什么、交付什么、怎样验收；礼貌不等于含糊。
- 同事：可以利用共享背景和协商语气，但涉及责任、期限和版本时仍要写出明确名词与动词。

## 六种句子任务

- 标题结论：`对象名词 + 判断/变化动词 + 结果或影响`。
- 数据证据：`数词 + 量词 + 对象名词 + 比较/变化动词 + 口径`。
- 原因解释：`事实或现象 + 因果连词 + 具体原因`；因果未证实时改用“可能与……有关”。
- 行动建议：`责任主体 + 时间副词 + 动词 + 对象 + 验收结果`。
- 风险边界：`对象 + 否定/范围副词 + 判断动词 + 限制条件`。
- 叙事过渡：按上下文选择代词、时间词和连接词；只在文章等叙事载体中适量使用助词、叹词和拟声词。

## 不能做的事

- 不把动词占比、虚词占比或平均句长单独当成“AI味”指标。
- 不为追求某个词性比例删掉数字、限定语、风险提示或正式名称。
- 不把教材、小说、诗歌和公众号文章混成一种“高级中文”。
- 不把平安PPT原材料直接并入通用语料。它只进入平安专属语料层，必须标明来源、载体、受众、句子任务、是否经用户确认和可复用边界。
