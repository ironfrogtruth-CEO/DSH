# 来源与语料使用规则

## 学习范围

把中小学语文教育、现代汉语语料、优秀现代文章、实用文体和用户真实材料作为互相校验的来源，不把任何一套教材或某一位作者的风格当成唯一标准。

### 课程标准

- 教育部《义务教育课程方案和课程标准（2022年版）》：确定语言积累、梳理、实用性阅读与交流、文学阅读与表达、思辨性表达等学习范围。
  - https://www.moe.gov.cn/srcsite/A26/s8001/202204/t20220420_619921.html
- 教育部《普通高中课程方案和语文等学科课程标准（2017年版2020年修订）》：确定语言建构与运用、思维、审美和文化等上位目标。
  - https://www.moe.gov.cn/srcsite/A26/s8001/202006/t20200603_462199.html

课程标准用来决定“要培养什么能力”，不直接充当句型模板。

### 现代汉语语料与语言规范

- 国家语委现代汉语语料库是大型通用语料库，可用于观察真实词语、句法和文体分布。
  - https://www.moe.gov.cn/jyb_xwfb/xw_zt/moe_357/s3580/moe_2448/moe_2450/moe_2461/tnull_40203.html
- `GB/T 15834-2011 标点符号用法`用于检查正式文本的标点规范。
  - https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=22EA6D162E4110E752259661E1A0D0A8

语料中的高频表达不一定是好表达；必须结合语境、读者和任务判断。

词性路由可以使用带文体标注和词性标注的现代汉语语料验证，但只观察“在什么载体、面向什么读者、承担什么句子任务时更常见”。不得从总词频直接推出“好中文必须达到某个比例”。

- 北京大学CCL现代汉语语料库按口语、应用文、报刊、文学、网络、翻译等语体保存语料，可用于比较载体差异。
  - https://corpus.pku.edu.cn/statistics/ccl_corpus_statistics.html
- 北京大学现代汉语多级加工语料库包含分词和词性等标注，可用于后续建立可复核的词性基线。
  - https://opendata.pku.edu.cn/dataset.xhtml?persistentId=doi:10.18170/DVN/SEYRX5

### 教材与作品

- 只使用合法获得或用户提供的教材、论文、文章和作品。
- 不把整套受版权保护的教材、范文或文学作品复制进 Skill。
- 保存可迁移的语言规律、短例、出处索引和必要的评价标签，不保存大段原文。
- 古诗文用于理解凝练、节奏、意象、语气和含蓄，不直接套写现代专业材料。

### 用户真实材料

用户确认过的标题、回复、报告和修改意见是风格校准材料，不自动成为事实来源。复用前必须分清：

- 哪些是长期偏好；
- 哪些只适用于当时的企业、项目或页面；
- 哪些是事实；
- 哪些只是表达示例。

## 五层语料库

语料按用途隔离，不能混在一个“中文风格库”里：

1. 教育与规范层：课程标准、合法获得的教材索引、语言规范。用于建立基础能力和边界。
2. 专业实用层：商业简报、邮件、报告、方案。用于校准正式表达和行动结构。
3. 文学审美层：小说、散文、诗歌。用于观察节奏、意象、视角和含蓄，只在合适文体中调用。
4. 公众传播层：经过筛选的公众号文章。用于观察解释方式和读者关系，不把流量套路当通用规则。
5. 用户与领域层：用户确认的材料及修改意见。按项目隔离，只提取已经确认、可迁移的表达偏好。

平安PPT原材料属于第五层的“平安专属语料”，不得进入通用正例库。语料索引至少记录：`source_id`、来源路径或出处、权限、载体、受众、句子任务、正反例标签、用户是否确认、受保护事实、可复用范围和污染状态。模型生成稿、未确认模板、调试输出和派生报告默认标记为待检或反例。

## 正例与反例

建立语料时同时保留正例和反例，并标注改动理由。标签至少覆盖：

- 文体和读者；
- 句子主体、动作和对象；
- 判断、证据、解释和建议；
- 句间关系；
- 标题类型；
- 翻译腔、空泛、重复、机械整齐、语气不当；
- 事实是否保持。

不能根据“像不像AI”一个模糊标签训练规则。每项判断必须指出真实读者能感知的问题。

## 污染与隔离

- 模型输出、旧模板和派生稿只能作为待检材料或反例，不能自动成为正例。
- 没有来源的网络“金句”、营销模板和所谓爆款公式不得进入通用规则。
- 行业规则放在行业 Skill，不写入通用表达层。
- 正式材料中的数字、术语和合规口径由真源与领域合同负责，本技能不得改写其含义。
