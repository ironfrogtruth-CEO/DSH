# 平安企康知识库引用纪律

依据：`知识库/00_总索引/检索与引用规范.md`、`术语口径与RAG引用规范.md`。

## 引用格式

```text
知识库路径：{分类目录}/{文件名}
来源组：{ROOT | PRESALE | NEWMAT | Q100 | QKTWEB | QKTLOCAL | MJKWEB}
源编号：Sxxx 或 Sxxx-Sxxx
结论：{提炼后的结论}
```

示例：

```text
知识库路径：02_服务与商品知识库/01_企康通服务/05_企康通产品服务体系.md
来源组：QKTLOCAL
源编号：QKTLOCAL-S001-S006
结论：企康通服务目录可用于报告中的服务建议，但价格、次数、履约时效和合同边界必须回源复核。
```

## 检索优先级

1. `00_总索引/分类目录索引.md` 查主题分类
2. `00_总索引/知识库文件清单.csv` 查具体文件
3. 进入对应分类目录读结构化正文
4. `90_来源追溯/{来源组}/_source_ocr/` 查事实源
5. `90_来源追溯/{来源组}/source_manifest.csv` 查源文件映射

## 可靠性红线（违反即阻断或标记 needs_review）

- 产品服务目录以 ROOT S071-S123 为主；价格、代码等受 OCR 影响的字段需回原系统复核。
- PRESALE：客户商标、人物肖像、价格、权益次数和服务范围外发前需复核授权和业务口径。
- NEWMAT：疫苗表、医学统计数据、价格和权益边界均需回源复核。
- Q100：正式对外前必须复核 OCR 错字、数字、服务承诺和合规判断。
- QKTWEB：首页服务目录可引用；深层页面、附件、价格、产品代码、权益次数、履约时效、案例详情和渠道声音不得扩写为确定结论。
- QKTLOCAL：可引用结构化产品、流程、合规和风格规则；原始文件名和原始路径不得进入 Wiki 正文或对客材料；价格、服务次数、时效、医院/医生数量、客户案例、内部插旗规则、合同条款和医学承诺均为 `needs_review`。

## 术语与边界

- 医典解释疾病/检查/科室/疫苗只做背景，不写诊断、处方、接种或检查建议。
- 禁止链路：医典疾病→直接生成平安服务；医典药品→直接生成商城商品；医典检查→直接生成体检加项；医典疫苗→直接生成接种建议。
- 服务/商品名不自造，不虚构价格、SKU、疗效承诺；案例不得把个案写成通用承诺。
- 企业指标只能由企业真源证明；知识库不能证明本企业人数、比例、费用、服务使用量或因果关系。
- 找不到来源的表述宁可标注待复核，不凭模型常识补写。
