# 平安企康知识库路由

本技能是**路由层，不是知识库本体**。知识库真源位于：

```text
/Users/marcus/Desktop/平安企康/平安健康知识库&技能/知识库/
素材库真源：/Users/marcus/Desktop/平安企康/平安健康知识库&技能/素材库/
```

知识库只提供背景、口径、服务承接、商品承接、视觉规范和合规边界；**客户项目的事实结论永远以用户原始材料、字段表、截图、明确口述和权威来源为准**。知识库不得替代企业数据，不得作为企业人数、比例、费用、服务使用量的证明。

## 第一步：先做路由判断

收到平安企康相关内容任务时，先对照下表判断"要不要查、查哪个库"。判断依据是任务里**可能出现的事实类别**，不是任务的名字。

| 任务里可能出现的内容 | 必查分库 | 典型任务 |
| --- | --- | --- |
| 疾病、药品、科室、检查、疫苗的解释或医学风险解读 | `01_医典知识库/` | 企业健康报告逐页稿、科普、体检解读、评估报告 |
| 平安服务/商品名、适用场景、履约路径、服务建议 | `02_服务与商品知识库/` | 报告推荐页、售前方案、服务书、药箱、商城方案 |
| 服务落地方式、运营动作、历史案例 | `03_客户运营与案例SOP/` | 履约方案、运营复盘、案例引用 |
| 报告/方案怎么写、述标/服务书表达方法 | `04_方法论与流程规范/` | 报告结构、述标材料、服务书 |
| 能不能这样说、这样卖、这样配（药品/商品/服务/采购/插旗） | `05_合规与风控/` | 任何客户可见材料发布前 |
| 页面视觉、组件、图标、图片、VI、HTML/PPT 调用规则 | `06_素材与视觉调用规范/` + `素材库/视觉组件外挂库/` | HTML/PPT 材料制作 |
| 需要核实某条知识的原始出处 | `90_来源追溯/` | 任何引用核验 |

**不需要查知识库的情形**：纯客户数据整理与确认（A01/A02 数据包）、纯渲染与排版、纯个人事务、已由用户确认的事实直接转述。这些场景跳过本技能，避免拖慢任务。

## 第二步：按最小调用链检索

需要查库时按以下顺序，不要跳跃：

1. 读 `00_总索引/分类目录索引.md` 定位知识域与具体文件；不确定域时先读 `00_总索引/LLM_Wiki知识库总入口.md`。
2. 用 `00_总索引/实体索引.csv`（风险、疾病、服务、商品、规则）和 `关系索引.csv` 交叉找关系。
3. 进入对应分库读具体条目（医典先读 `01_医典知识库/00_主题索引.md`；服务商品先读 `02_服务与商品知识库/00_服务商品分层与标签规范.md`）。
4. 需要核验原始出处时，进入 `90_来源追溯/{来源组}/` 看 `source_manifest.csv` 和 OCR 原文。
5. 引用时按引用纪律（见 `references/citation-rules.md`）输出：知识库路径、来源组、源编号、结论。

详细目录地图见 `references/kb-map.md`。素材调用规则见 `06_素材与视觉调用规范/`。

## 第三步：引用纪律（必须遵守）

引用格式固定为：

```text
知识库路径：{分类目录}/{文件名}
来源组：{ROOT | PRESALE | NEWMAT | Q100 | QKTWEB | QKTLOCAL | MJKWEB}
源编号：Sxxx / Sxxx-Sxxx / PRESALE### p## / Q100-Sxxx 等
结论：{提炼后的结论}
```

可靠性红线（取自官方检索与引用规范，违反即阻断）：

- 价格、代码、服务次数、履约时效、医院/医生数量、客户案例、合同条款、医学承诺，凡来自 OCR/站点采集的，一律标记 `needs_review`，不得写成确定结论。
- 客户商标、人物肖像、权益次数、服务范围外发前需复核授权与业务口径。
- 医典只做背景解释，**不得写诊断、处方、接种或检查建议**；医典疾病不得直接生成平安服务，医典药品不得直接生成商城商品。
- 服务/商品名不自造、不虚构价格和 SKU；案例不得把个案写成通用承诺。
- 知识库条目本身需要版本与来源可追溯；找不到来源的表述宁可标注待复核，不凭模型常识补写。

## 与其它技能的协作

- 企业健康报告生产链（`enterprise-health-report` 等 A00–A11 技能）会在各自节点调用知识库：A04 用医典解释，A05 用服务商品映射，A07 用医典/服务/合规，QA 闸门核对引用。本技能负责"开始前判断 + 检索定位 + 引用纪律"，两者叠加使用。
- `pingan-qikang-kb-curator` 负责知识库本身的摄取与维护；本技能只消费不修改。
- `pingan-html-materials` / `pingan-ppt-materials` 决定视觉表达，本技能决定事实来源，互不替代。

## 维护约定

知识库本体不复制进任何技能；本技能只是路由与纪律。知识库结构变化时，更新 `references/kb-map.md` 即可，不迁移知识库内容。
