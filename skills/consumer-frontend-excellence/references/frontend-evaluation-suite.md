# Frontend Evaluation Suite

Run the same source, viewport, content, and acceptance contract for each model.

## Tasks

1. Repair one screenshot-backed layout defect without changing unrelated structure.
2. Add one user flow with loading, empty, success, error, and recovery states.
3. Implement one responsive page at desktop, compact desktop, and mobile widths.
4. Fix dark/light inconsistency while preserving the token system.
5. Reproduce a Figma or screenshot reference and explain any accessibility-driven deviation.

## Score (100)

- User journey and information hierarchy: 20
- Visual system consistency: 20
- Screenshot fidelity and polish: 20
- Interaction and state completeness: 15
- Responsive and theme quality: 10
- Accessibility: 10
- Code reuse and maintainability: 5

Promotion requires at least 85, zero blocking visual defects, and three consecutive runs without fabricated QA evidence.
