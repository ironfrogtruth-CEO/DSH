# Consumer Visual System

## Foundation

- Typography: define display, title, body, label, helper, and code roles with explicit size, weight, and line height.
- Spacing: use a repeatable 4/8-based rhythm; exceptions must solve an optical problem.
- Radius: use a small controlled set tied to control, card, and overlay roles.
- Elevation: use the fewest layers needed to communicate base, raised, and modal surfaces.
- Color: assign semantic roles for background, surface, text, border, brand, success, warning, and danger in both themes.
- Width: define readable content widths and prevent uncontrolled line length.
- Icons: use one family, stable optical size, and consistent stroke weight.
- Motion: define duration and easing by feedback, transition, and overlay roles.

## Hierarchy

1. Give the primary task the strongest placement and contrast.
2. Place controls next to the content they affect.
3. Keep supporting information quieter without making it illegible.
4. Use cards only when a boundary changes meaning, ownership, or action scope.
5. Avoid multiple primary buttons in one decision area.

## Consistency

- Reuse a component when semantics match; create a variant when only appearance or density changes.
- Do not copy a component and silently change padding, radius, or icon alignment.
- Treat selected, active, hover, and focus as different states.
- Use identical terminology for the same object and action across navigation, headers, dialogs, and feedback.
